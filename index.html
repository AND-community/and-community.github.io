A forum with no server in the middle.

AND runs in your terminal. Topics, chat and private messages travel directly between the people using it, each signed with a key that only its author holds. There are no accounts and no central server.

What’s in it

Everything here runs on your computer and on the computers of the people you talk to.

Forum
34 categories. A topic reaches peers the moment it’s posted and deletes itself after 5 days.
Chat
One public channel. Messages are signed, not encrypted, and kept for 48 hours.
Private messages
Sent straight to the other person over an encrypted connection. If they’re offline, AND keeps the message and delivers it when they’re back, for up to 7 days.
Files
Send a file to a peer. Nothing arrives without the recipient’s approval, and interrupted transfers resume.
Personal site
Publish up to 20 pages of your own. They’re signed and synced like the forum, and your edits reach everyone.
Moderation
The founder signs moderator certificates. Moderators can delete topics early and ban peers for an hour or for good; every decision is signed and logged.
Plugins
Separate programs that extend AND. Each one asks for the permissions it needs the first time you open it.
Themes and languages
Six built-in themes, and an interface in Turkish, English, German, Spanish, French and Russian.
Updates
Official releases update themselves and their plugins, and only after the release’s signature checks out.
Search
The AND Search Engine joins the network as a read-only peer and makes forum, chat and site content searchable from the terminal.

How it works

AND has no server to send things to. Every computer running it is a node: it keeps its own copy of what it receives and passes new messages on to the nodes it’s connected to.

  1. You post a topic. AND signs it with your key and publishes it to the nodes you’re connected to.
  2. The nodes pass it on. Every node checks the signature before storing anything, and discards messages that are unsigned or have been altered.
  3. Each node keeps its own copy in a local database. Topics delete themselves after 5 days, chat messages after 48 hours.
  4. A node that was offline catches up when it reconnects, by syncing the history it missed directly with its peers.

Nodes find each other through the public libp2p DHT on the internet and through mDNS on your local network. Connections are encrypted with the Noise protocol. If you’re behind a NAT, a relay can carry the encrypted traffic, but it can’t read it.

Get AND

AND runs in a terminal on Windows, Linux and macOS.

Every release has a ready-to-run archive for each platform on the Releases page.

Build from source

You need Go 1.26.4 or later. These commands build AND and Konu Aç, the plugin that lets you start topics:

git clone https://github.com/AND-community/AND.git
cd AND
go build -o and ./cmd/and
git clone https://github.com/AND-community/konu_ac.git Eklentiler/konu_ac
go build -o Eklentiler/konu_ac/and-plugin-konu_ac ./Eklentiler/konu_ac
./and

On Windows, add .exe to the output names and run and.exe. The README covers every plugin and build option.

Security

AND is built so that you don’t have to trust a server, and it tells you plainly what others can see.

Your identity
An Ed25519 key pair made on your computer from 128 bits of randomness and stored encrypted with your password (Argon2id and AES-256-GCM). The 32-character recovery code you get when you create it is the only way to restore it.
Signatures
Every topic, reply, chat message and moderation decision is signed. Nodes reject anything that’s unsigned or has been altered.
What’s public
Topics, replies, chat, profiles and personal sites are public: they spread to other nodes and are stored there. AND is pseudonymous, not anonymous; the nodes you connect to can see your IP address.
Private messages
They travel over a direct, encrypted connection, and your message history is stored encrypted on your computer.
Updates
Before replacing anything, an official release checks the release’s SHA-256 checksums and their Ed25519 signature. Builds you make from source never update themselves.

Plugins
Each plugin runs as a separate program with its own API key and only the permissions you approved.
Your terminal
Text from the network is cleaned of escape sequences and control characters before it’s drawn.
Telemetry
None. AND doesn’t collect or send usage data or crash reports.

Questions

Is AND anonymous?

No. AND is pseudonymous: you appear under a name and a key rather than your real identity, but the nodes you connect to can see your IP address. AND doesn’t hide it for you.

Do I need a server, a domain or an account?

No. Install AND, pick a name and a password, and you’re on the network. Every node is both a client and a server.

How long do posts stay?

Topics delete themselves 5 days after they’re posted, chat messages after 48 hours. Content that has already spread can’t be guaranteed to disappear from every node.

I forgot my password.

Press ctrl+r on the login screen and type your recovery code. AND restores your identity and asks for a new password.

I lost my recovery code.

If you still know your password, open Settings, go to the Info tab and press m to show the code. If you’ve lost both, nobody can restore your identity: it never leaves your computer.

Which systems does it run on?

Windows, Linux and macOS, in any terminal. Releases are built for x86-64 on all three, and for ARM64 on Linux and macOS.

Is it free?

Yes. AND is free software under the GNU AGPL-3.0: you can use, study, change and share it. If you run a modified version for others over a network, you have to offer them its source code.

Can I write my own plugin?

Yes. A plugin is a separate program that talks to AND over a local HTTP API, with its own key. Start from the example plugin and its guide (in Turkish).

Who moderates?

The founder, whose key is built into AND, and the moderators the founder appoints with signed certificates, which can be revoked at any time. They can delete topics early and ban peers; every node checks each decision’s signature.
